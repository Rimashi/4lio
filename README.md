# 📚 4lio — Электронная библиотека

Экзаменационный проект по веб-разработке.  
Автоматизированная информационная система для ведения реестра книг, читателей, рецензий и подборок.

---

## Технологии

- **Backend**: Python 3.11, Flask, Flask-Login, Flask-SQLAlchemy, Flask-Migrate
- **Database**: PostgreSQL
- **Frontend**: HTML5, CSS3 (BEM), JavaScript (jQuery), EasyMDE (Markdown)
- **Deployment**: возможно располагается по пути https://4lio.rimashi.ru/. Иначе временно отсутствует..

---

## Реализованный функционал

### Основное ТЗ

- Регистрация и аутентификация пользователей (с ролями)
- Каталог книг с пагинацией (10 книг на страницу)
- Фильтрация по названию, автору, жанру, году, количеству страниц
- Просмотр книги: обложка, описание (Markdown), метаданные, рейтинг
- Добавление/редактирование/удаление книг (с разграничением прав)
- Загрузка обложек с проверкой MD5-хэша (дубликаты не сохраняются)
- Написание рецензий с оценкой (звёздный рейтинг) и текстом (Markdown)
- Модерация рецензий (одобрение/отклонение)
- Личный кабинет пользователя: профиль, история просмотров
- Статистика для администратора (журнал действий и просмотры книг)
- Экспорт данных в CSV
- Адаптивный дизайн, тёмная тема, мобильное меню

### Вариант 1 (основной) — Модерация рецензий

- Рецензии имеют статусы: «На рассмотрении», «Одобрена», «Отклонена».
- Пользователь видит свои рецензии в разделе «Мои рецензии» с указанием статуса.
- Модератор и администратор имеют доступ к разделу «Модерация», где видят рецензии, ожидающие рассмотрения.
- Реализована пагинация списка рецензий на модерации.
- При просмотре конкретной рецензии модератор может одобрить или отклонить её.

### Дополнительно реализовано (из других вариантов)

- **Вариант 3** — Поиск книг с фильтрацией по всем полям (название, автор, жанр, год, объём).
- **Вариант 4** — Блоки «Недавно просмотренные» и «Популярные книги» (за 3 месяца) на главной странице; история просмотров для каждого пользователя (с ограничением 10 просмотров в день).
- **Статистика** — для администратора: журнал действий пользователей и статистика просмотров книг (с фильтром по датам, пагинация, экспорт CSV).

## Дамп базы данных

### Для проверки структуры и данных приложены файлы:

- schema.sql — только структура таблиц.
- database.sql — полный дамп (структура + данные).

### Восстановление дампа (PostgreSQL)

```bash
psql -U postgres -d folio < database.sql
```

## Примечания

- Используется PostgreSQL (не MySQL).
- Все внешние ключи имеют ON DELETE CASCADE для каскадного удаления.
- Для Markdown используется библиотека markdown с санитайзингом через bleach.
- Обложки сохраняются с уникальными именами (на основе MD5-хэша) во избежание дублей.
- Авторизация через Flask-Login, пароли хэшируются с помощью Werkzeug.

## Установка и запуск

### Клонирование репозитория

```bash
git clone https://github.com/Rimashi/4lio.git
cd 4lio
```

### Создание виртуального окружения

```bash
python3 -m venv venv
source venv/bin/activate  # Linux/Mac
# или
venv\Scripts\activate  # Windows
```

### Установка зависимостей

```bash
pip install -r requirements.txt
```

### Настройка переменных окружения

#### Создайте файл .env в корне проекта:

```bash
FLASK_SECRET_KEY=your-secret-key
PG_USER=postgres
PG_PASSWORD=your_password
PG_HOST=localhost
PG_PORT=5432
PG_DB=folio
UPLOAD_FOLDER=static/uploads
```

### Создание и наполнение базы данных

#### 1. Создайте базу данных PostgreSQL (например, folio).

#### 2.Примените миграции (или создайте таблицы вручную, если миграции не используются):

```bash
flask db upgrade
```

#### 3. Заполните начальными данными (роли, жанры, тестовые пользователи и книги):

```bash
python seed.py
```

## Запуск приложения

```bash
flask run
```
